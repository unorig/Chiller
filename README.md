# Chiller (Commodore64) source code
This is the decompiled source code for Chiller for the Commodore 64. 

## The code

The code has previously been disassembled using various tools but now leveraging [@ricardoquesada](https://github.com/ricardoquesada)'s [regenerator2000](https://github.com/ricardoquesada/regenerator2000). If you are not familiar with Richardo's work, I highly recommend you check out his work on reverse engineering Commando to create [Commando 2084](https://github.com/ricardoquesada/c64-commando-2084). He also had a blog explaining his work [here](https://retro.moe/2019/10/02/commando-disassembled-fully-commented-code/).

## Music
Chiller features a famously controversial soundtrack by composer David Dunn, which originally included an unlicensed, note-for-note chiptune rendition of Michael Jackson's Thriller. Mastertronic ultimately pulled and re-released the game with a replacement theme due to copyright issues.

This codebase has both versions of the music available in the [music folder](https://github.com/unorig/Chiller/tree/Latest/Music). The different versions of the music can be seen on the [youtube video](https://www.youtube.com/watch?v=6kFu5ojgnQU).
